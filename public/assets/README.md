# Assets de Imágenes

Coloca las siguientes imágenes en esta carpeta `/public/assets/`:

## Imágenes requeridas:

1. **logo-galileo.png** - Logo oficial de la Logia Galileo Nº 3
   - Tamaño recomendado: 512x512px o superior
   - Formato: PNG con fondo transparente

2. **victor-rendon.png** - Fotografía histórica de Víctor A. Rendón
   - Formato: PNG o JPG
   - Fotografía histórica en sepia/blanco y negro

3. **david-vivas.png** - Fotografía histórica de David Vivas Romero
   - Formato: PNG o JPG
   - Fotografía histórica en sepia/blanco y negro

4. **enrique-aznar.png** - Fotografía histórica de Enrique Aznar Mendoza
   - Formato: PNG o JPG
   - Fotografía histórica en sepia/blanco y negro

## Instrucciones:

1. Descarga las imágenes desde Figma Make (si aún tienes acceso)
2. Renómbralas exactamente como se indica arriba
3. Colócalas en esta carpeta `/public/assets/`
4. Elimina este archivo README.md si lo deseas

## Alternativa:

Si no tienes acceso a las imágenes originales, puedes:
- Usar imágenes de placeholder temporalmente
- Reemplazarlas con las imágenes correctas cuando las tengas disponibles
